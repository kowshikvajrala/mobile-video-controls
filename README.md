# Mobile Video Controls

A Tampermonkey userscript that adds a clean, mobile-first fullscreen player to any video on any site. Built for Android browsers.

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your mobile browser (e.g. Firefox for Android, Kiwi, Edge).
2. Open [mobile-video-controls.user.js](https://raw.githubusercontent.com/kowshikvajrala/mobile-video-controls/main/mobile-video-controls.user.js) and tap **Install**.

Tampermonkey checks this repo for updates automatically.

## Usage

Tap the floating button (bottom right) on any page with a video.

| Gesture | Action |
| --- | --- |
| Tap | Show / hide controls |
| Double-tap left / right | Back / forward 10s (keep tapping to add more) |
| Double-tap center | Play / pause |
| Swipe left / right | Seek |
| Hold | Play at 2x while held |
| Rotate button (top bar) | Landscape (fullscreen) or portrait (keeps browser bar visible) |
| Back button | Close the player |

Keyboard: Space/K play-pause, ←/→ or J/L seek, F fullscreen, Esc close.
